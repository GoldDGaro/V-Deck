# V-Deck

## Русский

VPN-плагин для Decky Loader на Steam Deck. Импортируйте конфигурацию совместимого протокола и управляйте подключением из интерфейса плагина.

Это предварительная версия. Совместимость зависит от конфигурации, сервера и окружения SteamOS. Отдельные возможности могут быть экспериментальными.

Установочный ZIP и соответствующие исходники компонентов доступны в [релизах](https://github.com/GoldDGaro/V-Deck/releases). Лицензия проекта указана в LICENSE; лицензии сторонних компонентов — в THIRD_PARTY_NOTICES.md.

## English

A VPN plugin for Decky Loader on Steam Deck. Import a supported configuration and manage the connection from the plugin interface.

This is a preview version. Compatibility depends on the configuration, server and SteamOS environment. Some features may be experimental.

The installer ZIP and corresponding component source are available in [Releases](https://github.com/GoldDGaro/V-Deck/releases). See LICENSE for the project license and THIRD_PARTY_NOTICES.md for third-party licenses.
