# Changelog

## 0.2.0 — 2026-09-24, public preview

- Add Amnezia Premium subscription import and country selection.
- Add experimental Xray VLESS Reality client JSON and URI import.
- Add daily logs with a three-calendar-day retention window.
- Improve connection lifecycle, IPv4/IPv6 routing, MTU selection and cleanup.
- Improve tunnel latency display, DNS checks and transient-error handling.
- Update bundled-client support, build checks and installation instructions.

This remains a preview; see [README](README.md). Compatibility with every
server, network and protocol combination is not guaranteed.

## 0.1.0-preview.2 — 2026-09-07

- Improve configuration import and error reporting.
- Improve VPN process handling, system-command environment and network cleanup.
- Improve auto-connect and recovery after network changes.
- Add manual external IPv4 checks and update RU/EN instructions.
- Correct interface layout and translations.

## 0.1.0 — 2026-08-31

- Initial preview with AmneziaWG, WireGuard and OpenVPN profiles.
- Add one-active-VPN management, auto-connect, recovery and optional Kill Switch.
- Add RU/EN interface, diagnostics and bundled Linux x86_64 clients.
